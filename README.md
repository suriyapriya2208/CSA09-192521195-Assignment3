## How to run
1. Open this entire folder in VS Code.
2. Open **Terminal → New Terminal**.
3. Move into the task folder, for example:
   ```powershell
   cd Task01_ATM
   ```
4. Compile:
   ```powershell
   javac *.java
   ```
5. Run the class shown in that task's README, for example:
   ```powershell
   java ATM
   ```

Use `java -version` and `javac -version` to confirm Java is available.
